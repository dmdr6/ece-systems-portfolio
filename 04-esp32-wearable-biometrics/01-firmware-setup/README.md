# Task 1: ESP32 Firmware & Environment Setup

## Objective
Configure the toolchain, establish board communications, and manage dependencies for the ESP32 wearable platform.

## Configuration Details
- **Microcontroller:** ESP32 Dev Module (`esp32dev`)
- **Framework:** Arduino C++
- **Build System:** PlatformIO / VS Code

## Dependencies
- Adafruit SSD1306 & GFX Library
- Adafruit MPU6050
- SparkFun MAX3010x Pulse Sensor Library

## Verification
- Confirmed Serial UART communication over USB.
- Built and flashed baseline firmware environment successfully.
